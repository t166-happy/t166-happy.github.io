# AI 學術論文研究助手 Ultimate 安裝下載頁

這是可放在 GitHub Pages 專案子路徑的靜態頁面。無外部字型、第三方程式、分析碼或後端。

## 本機預覽

將交付檔放入下列位置。於本資料夾啟動 `python -m http.server 8000`，然後開啟 `http://localhost:8000/`。若不提供選用的 MCP 檔案，請同步移除網頁中該下載連結。

```text
index.html
style.css
.nojekyll
downloads/
  academic-research-assistant-ultimate-skill.zip
  install-guide.pdf
  user-guide.pdf
  apa7-student-template.docx
  mcp-gateway-sel.zip
```

## GitHub Pages 發布

把上述檔案放在 Pages 所用分支與發布資料夾，例如 `main` 的 repo 根目錄。到該 repo 的 Settings → Pages，選擇 Deploy from a branch 與相應來源。發布後核對首頁及每個下載連結可從專案子路徑打開，再分享網址。

網站只提供安裝步驟和靜態下載，不會替訪客安裝 Skill、部署 MCP 或連接 ChatGPT。若下載檔內含個人資訊或機密，應先移除再公開。
